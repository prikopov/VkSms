# VkSms для Windows

Мониторинг свежих публикаций ВКонтакте и отправка SMS через Android по USB. Внешний SMS-сервис и Python для запуска EXE не нужны. SMS отправляются с SIM подключённого телефона.

> [!IMPORTANT]
> **Требуется предварительное согласие.** Получите согласие человека на обработку его номера телефона и на получение именно таких SMS. Публикация номера в открытом посте сама по себе не означает согласия. VkSms не проверяет согласие автоматически. Если согласие отсутствует, отозвано или его нельзя подтвердить для каждого получателя, не включайте режим отправки.

[Скачать сборку для Windows x64](https://github.com/prikopov/VkSms/releases/latest)

## Запуск

1. Распакуйте архив целиком. Запустите **VkSms.exe**, оставьте режим **Демо** и нажмите **Один цикл**. В таблице появится один условный номер со статусом «Демо», хотя в примере он встречается в двух записях. Для демо телефон и токен не нужны.
2. В [«Мои приложения» ВК](https://vk.com/apps?act=manage) откройте настройки своего приложения, скопируйте **Сервисный ключ доступа** и вставьте его в поле **Токен ВК**. У ключа должен быть доступ к **newsfeed.search**. Выберите **Поиск без SMS** и нажмите **Один цикл**. Этот режим сохраняет совпадения в рабочую базу, из которой режим отправки берёт ещё свежие записи.
3. На Android 7.0 или новее с активной SIM включите отладку по USB, подключите телефон кабелем и подтвердите отладку на экране телефона. При нескольких SIM укажите SIM по умолчанию для SMS. Программа ищет ADB в установленном Android SDK, в PATH и в папке platform-tools рядом с EXE. Если ADB отсутствует, скачайте [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) и распакуйте эту папку рядом с EXE. При нескольких телефонах впишите нужный серийный номер из команды adb devices -l.
4. В Windows нажмите **Установить APK**. На телефоне в **VkSms USB** нажмите **Разрешить отправку SMS** и подтвердите разрешение Android. В Windows нажмите **Проверить телефон**. На некоторых моделях в настройках разработчика нужно также разрешить установку по USB.
5. Введите текст SMS и выберите **Поиск и отправка SMS**. Кнопка **Один цикл** запускает одну проверку, **Запустить** повторяет её с выбранным интервалом. Для фоновой работы оставьте окно открытым и компьютер включённым.

## Что сохраняется

- По умолчанию проверка каждые 5 минут, берутся посты за последние 20 минут. Интервал можно менять от 5 до 10 минут, окно свежести — до 60 минут. Поиск идёт по выдаче ВК. Программа дополнительно проверяет время публикации и наличие заданной фразы в тексте.
- Номера в формате +7, 7 и 8 нормализуются в +7. Для каждого номера в рабочей базе есть одна запись. Пока он в очереди, более свежий пост может обновить ссылку. Устаревшая запись не отправляется. За один цикл обрабатывается до 50 ожидающих номеров.
- Демо хранится в отдельной базе и не использует VK или ADB. Режим поиска сохраняет найденные номера в рабочую базу. Получите согласие на обработку номеров до поиска с реальными данными.
- Если Android уже получил задание, Windows запрашивает его статус у того же телефона. Задания с неизвестным исходом не отправляются повторно автоматически. При временном обрыве подключите прежний телефон и снова запустите рабочий режим. Статус «Отправлено» означает подтверждение отправки от Android, доставку абоненту программа не отслеживает.
- Таблица показывает до 500 последних записей. Полная история в SQLite. Кнопка **Папка данных** открывает %LOCALAPPDATA%\VkSms. Рабочая база называется recipients.sqlite3, настройки — settings.json. Токен ВК сохраняется локально в settings.json. Для защиты от дублей сохраняйте рабочую базу между запусками.

Поиск использует [официальную схему VK API](https://github.com/VKCOM/vk-api-schema/blob/master/newsfeed/methods.json). Она описывает метод и формат запроса. Фактический доступ впервые проверяется с вашим токеном через режим «Поиск без SMS».

## Исходники

- sources\app.py — окно Windows и настройки.
- sources\bot.py — поиск ВК, нормализация телефонов, SQLite, очередь и протокол Android.
- sources\android — модуль Android.
- Windows EXE собирается через PyInstaller. Из папки sources выполните: python -m PyInstaller --onefile --windowed --name VkSms app.py
- APK собирается через sources\Build-Android.ps1. Нужны Java JDK, Python, Android SDK Platform 36 и Build Tools 36.0.0. Скрипт создаёт локальный ключ подписи при первом запуске. Для установки обновления поверх ранее установленного APK нужен тот же ключ подписи. Ключ в архив не включён.
